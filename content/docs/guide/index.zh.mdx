RouteMarket 的使用流程分成账户准备、客户端配置、API 接入和问题排查四部分。

## 第一次使用

如果你是第一次使用 RouteMarket，完整的分步开通流程见 [注册与开通](/zh/getting-started)（含注册、登录、充值、建密钥、环境检查、配置 CLI 六步）。

开通完成后：

1. 选择聊天客户端、图片工作台或 API 接入方式。
2. 用一个低成本请求验证密钥、模型与网络配置。
