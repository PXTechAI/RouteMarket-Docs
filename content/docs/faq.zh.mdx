## RouteMarket 是 OpenAI 的替代品吗？

不是。更准确地说，RouteMarket 是一个统一的 AI 网关与控制平台。

它的价值在于：

- 统一接入多模型
- 统一管理来源
- 统一治理项目、限额和预算
- 统一记录用量与计费

## RouteMarket 和普通 API 中转有什么差别？

核心差别在于它不是只做转发，而是把这些能力平台化：

- 逻辑模型与来源解耦
- 多来源 route 选择
- 项目 / Key 级访问策略
- 用量、来源和价格可见

## 我是不是必须手动选 provider？

不需要。大多数情况下只请求逻辑模型名就可以。

只有当你需要更明确的控制时，才会加上：

- `provider`
- `route`
- `routing_preference`

## `model` 字段填的到底是什么？

通常填的是**逻辑模型名**，而不是某个 provider 的底层原始模型标识。

例如：

- `gpt-5.4`
- `claude-sonnet-4`

## RouteMarket 会不会自动换来源？

会，但前提是：

- 该请求没有被禁止 fallback
- 项目和 Key 策略允许
- 存在其他可用候选 route

如果你显式指定了某个不可访问的 route，系统应该返回明确错误，而不是悄悄换掉。

## docs 站现在是独立服务吗？

是的。`docs.routemarket.ai` 现在已经是独立的 `apps/docs` 应用，并通过独立 Docker target 和生产服务部署。
