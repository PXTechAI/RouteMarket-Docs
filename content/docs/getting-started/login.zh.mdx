访问 [控制台登录页](https://console.routemarket.ai/login)，使用 Google/Github/MetaMask 账号或邮箱 + 密码登录。

<DocImage src="/images/docs/getting-started/login.png" alt="RouteMarket 登录页面示意" caption="注册页面" />

## 登录异常排查

如果登录后提示鉴权失败或页面异常，通常是浏览器缓存导致：

1. 清除浏览器缓存：`Ctrl+Shift+Delete`（Windows / Linux）或 `Cmd+Shift+Delete`（macOS）。
2. 或者手动清除 Cookie：打开开发者工具（`F12`）→ Application / 存储 / 应用 → Cookies → 找到控制台域名 → 删除相关会话 Cookie。
3. 刷新页面重新登录。
<DocImage src="/images/docs/getting-started/cookie.png" alt="RouteMarket 登录页面示意" caption="Cookie清除" />



登录成功后，继续 [购买额度/卡密兑换](/zh/getting-started/quota)。
