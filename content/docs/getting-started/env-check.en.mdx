---
title: 5. Check your environment
description: Confirm Node.js is installed before configuring a CLI tool.
---

Most RouteMarket-supported CLI tools depend on Node.js. Before configuring one, confirm it's installed locally:

```bash
npm list -g --depth-0
```

If the command errors out or Node.js isn't installed, install the latest LTS release first, then continue.

Once confirmed, continue to [Configure your CLI tool](/en/getting-started/cli-setup).
