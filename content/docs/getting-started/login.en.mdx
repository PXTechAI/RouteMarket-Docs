## Troubleshooting login issues

If login fails with an authentication error or the page misbehaves, it's usually a browser cache issue:

1. Clear your browser cache: `Ctrl+Shift+Delete` (Windows/Linux) or `Cmd+Shift+Delete` (macOS).
2. Or manually clear cookies: open DevTools (`F12`) → Application → Storage → Cookies → find the console domain → delete the session cookies.
3. Refresh and log in again.

Once logged in, continue to [Purchase quota](/en/getting-started/quota).
