本页整理 RouteMarket 的 **Seedance 2.0 Fast** 兼容接口，包括可识别的端点、结构化参数和请求示例。

> 兼容性提示：页面由公开协议中的技术字段生成。具体模型、额度和路由能力以 RouteMarket 控制台及实际网关响应为准。

## 参数参考

### 参数表 1

| 能力 | 方法 | 路径 |
| ---- | ------ | -------------------- |
| 提交任务 | `POST` | `/v1/task/submit` |
| 查询任务 | `GET` | `/v1/task/{task_id}` |

### 参数表 2

| 组合 | 是否支持 | 说明 |
| -------------- | ---- | --------------------------------------------------------- |
| 纯文生视频 | 支持 | - |
| 参考图 + 参考视频 | 支持 | 相关值：`image_references`、`video_references` |
| 参考图 + 参考音频 | 支持 | 相关值：`image_references`、`audio_references` |
| 首帧 | 支持 | 相关值：`start_frames[0]`、`0` |
| 首帧 + 尾帧 | 支持 | 相关值：`start_frames[0]`、`end_frames[0]`、`0` |
| 单独尾帧 | 不支持 | 相关值：`end_frames`、`start_frames` |
| 参考图 + 首/尾帧 | 不支持 | 相关值：`image_references`、`start_frames`、`end_frames` |
| 首/尾帧 + 参考视频/音频 | 不支持 | 相关值：`video_references`、`audio_references` |

### 参数表 3

| aspect\_ratio | 480p | 720p |
| ------------- | --------- | ---------- |
| `21:9` | `992x432` | `1470x630` |
| `16:9` | `864x496` | `1280x720` |
| `4:3` | `752x560` | `1112x834` |
| `1:1` | `640x640` | `960x960` |
| `3:4` | `560x752` | `834x1112` |
| `9:16` | `496x864` | `720x1280` |

### 参数表 4

| 场景 | 建议 |
| ------ | --------------------------------------------------------------------- |
| 常规视频任务 | 优先使用 `seedance-2.0-fast`，速度和能力覆盖更均衡 |
| 需要更高清 | 使用 [`seedance-2.0`](/zh/api/async-video/api-async-video-seedance-2-0)，它额外支持 `1080p` |
| 首尾帧 | 只传 `start_frames` 和 `end_frames`，不要再混入参考图、参考视频或参考音频 |
| 素材 URL | 需要公网可访问；本地文件请先上传或转为 data URI / base64 |

## 请求与响应示例

### 示例 1

```text
Authorization: Bearer $ROUTEMARKET_API_KEY
```

### 示例 2

```json
{
  "id": "task_xxxxxxxxxxxxxxxx",
  "status": "queued",
  "phase": "queued",
  "created_at": 1760000000,
  "progress": null
}
```

### 示例 3

```bash
curl https://api.routemarket.ai/v1/task/task_xxxxxxxxxxxxxxxx \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY"
```

### 示例 4

```json
{
  "id": "task_xxxxxxxxxxxxxxxx",
  "status": "completed",
  "phase": "completed",
  "outputs": [
    "https://api.routemarket.ai/videos/task_xxxxxxxxxxxxxxxx_0.mp4"
  ],
  "error": null
}
```

## 接入说明

- API 基础地址：`https://api.routemarket.ai`
- 推荐密钥环境变量：`ROUTEMARKET_API_KEY`
- 请求使用 `Authorization: Bearer <API_KEY>`。
- 上线前请用实际账号验证端点、模型名、限额与异步任务状态。
