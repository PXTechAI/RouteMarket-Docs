本页整理 RouteMarket 的 **Grok Imagine 1.5** 兼容接口，包括可识别的端点、结构化参数和请求示例。

> 兼容性提示：页面由公开协议中的技术字段生成。具体模型、额度和路由能力以 RouteMarket 控制台及实际网关响应为准。

## 参数参考

### 参数表 1

| 能力 | 方法 | 路径 |
| ---- | ------ | -------------------- |
| 提交任务 | `POST` | `/v1/task/submit` |
| 查询任务 | `GET` | `/v1/task/{task_id}` |

### 参数表 2

| aspect\_ratio | 480p | 720p |
| ------------- | --------- | ---------- |
| `1:1` | `544x544` | `960x960` |
| `16:9` | `736x400` | `1280x720` |
| `9:16` | `400x736` | `720x1280` |

### 参数表 3

| 场景 | 建议 |
| ------ | ------------------------------------------------------------------------------------- |
| 已有确定画面 | 使用 `grok-imagine-1.5`，把图片作为首帧传入 |
| 纯文生视频 | 不适合本模型，建议使用 [`gemini-omni-flash`](/zh/api/async-video/api-async-video-gemini-omni-flash) 或 Seedance |
| 多图参考 | 不适合本模型，建议使用 [`happy-horse-1.1`](/zh/api/async-video/api-async-video-happy-horse-1-1) |
| 首帧数量 | 只传 1 张，避免把参考图误传成首帧列表 |

## 请求与响应示例

### 示例 1

```text
Authorization: Bearer $ROUTEMARKET_API_KEY
```

### 示例 2

```json
{
  "id": "task_xxxxxxxxxxxxxxxx",
  "status": "queued",
  "phase": "queued",
  "created_at": 1760000000,
  "progress": null
}
```

### 示例 3

```bash
curl https://api.routemarket.ai/v1/task/task_xxxxxxxxxxxxxxxx \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY"
```

### 示例 4

```json
{
  "id": "task_xxxxxxxxxxxxxxxx",
  "status": "completed",

  "outputs": [
    "https://api.routemarket.ai/videos/task_xxxxxxxxxxxxxxxx_0.mp4"
  ],
  "error": null

```

## 接入说明

- API 基础地址：`https://api.routemarket.ai`
- 推荐密钥环境变量：`ROUTEMARKET_API_KEY`
- 请求使用 `Authorization: Bearer <API_KEY>`。
- 上线前请用实际账号验证端点、模型名、限额与异步任务状态。
