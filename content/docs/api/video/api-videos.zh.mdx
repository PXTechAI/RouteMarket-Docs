> 兼容性提示：页面由公开协议中的技术字段生成。具体模型、额度和路由能力以 RouteMarket 控制台及实际网关响应为准。

## 接口地址

- `DELETE https://api.routemarket.ai/v1/videos/task_xxx`

## 参数参考

### 参数表 1

| 能力 | 方法 | 路径 | 说明 |
| ---- | -------- | ------------------------------- | --------- |
| 创建任务 | `POST` | `/v1/videos` | - |
| 查询任务 | `GET` | `/v1/videos/{video_id}` | - |
| 下载文件 | `GET` | `/v1/videos/{video_id}/content` | - |
| 删除任务 | `DELETE` | `/v1/videos/{video_id}` | - |

### 参数表 2

| 模型 | 说明 |
| -------- | ------------------ |
| `sora-2` | - |

### 参数表 3

| status | 说明 |
| ------------- | ----------------------- |
| `queued` | - |
| `in_progress` | - |
| `completed` | - |
| `failed` | 相关值：`error.message` |

### 参数表 4

| 问题 | 处理方式 |
| ------ | ---------------------------- |
| 查询不到任务 | 检查 `video_id` 是否为创建响应里的 `id` |
| 一直生成中 | 视频任务耗时较长，建议每 2 到 3 秒轮询一次 |
| 下载失败 | 优先使用 `output` 直链，或稍后重试下载接口 |

### 示例 7

```python
import time
import requests

API_BASE = "https://api.routemarket.ai"
API_KEY = "sk-xxx"

task = requests.post(
    f"{API_BASE}/v1/videos",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "model": "sora-2",
        "prompt": "镜头缓慢推进，一只未来感狐狸站在雨夜霓虹街头",
        "size": "1280x720",
        "seconds": "8",
    },
    timeout=60,
).json()

task_id = task["id"]

while True:
    result = requests.get(
        f"{API_BASE}/v1/videos/{task_id}",
        headers={"Authorization": f"Bearer {API_KEY}"},
        timeout=60,
    ).json()

    if result["status"] == "completed":
        print(result["output"])
        break

    if result["status"] == "failed":
        raise RuntimeError(result.get("error", {}).get("message", "生成失败"))

    time.sleep(3)
```
