本页整理 RouteMarket 的 **Gemini Generate Content** 兼容接口，包括可识别的端点、结构化参数和请求示例。

> 兼容性提示：页面由公开协议中的技术字段生成。具体模型、额度和路由能力以 RouteMarket 控制台及实际网关响应为准。

## 参数参考

### 参数表 1

| 能力 | 方法 | 路径 |
| ---- | ------ | ---------------------------------------------- |
| 生成内容 | `POST` | `/v1beta/models/{model}:generateContent` |
| 流式生成 | `POST` | `/v1beta/models/{model}:streamGenerateContent` |

### 参数表 2

| 字段 | 说明 |
| ------------------ | ----------- |
| `text` | - |
| `inlineData` | - |
| `fileData` | - |
| `functionCall` | - |
| `functionResponse` | - |

### 参数表 3

| 字段 | 类型 | 说明 |
| ---------------- | ------ | --------------- |
| `candidates` | array | - |
| `usageMetadata` | object | - |
| `modelVersion` | string | - |
| `responseId` | string | - |
| `promptFeedback` | object | - |

### 参数表 4

| 字段 | 说明 |
| --------------- | ------------------------------------ |
| `content.parts` | - |
| `finishReason` | 相关值：`STOP`、`MAX_TOKENS`、`SAFETY` |
| `safetyRatings` | - |

### 参数表 5

| 参数 | 说明 |
| ----------------------------------- | -------------------------------- |
| `generationConfig.temperature` | - |
| `generationConfig.topP` | - |
| `generationConfig.topK` | - |
| `generationConfig.maxOutputTokens` | - |
| `generationConfig.responseMimeType` | 相关值：`application/json` |
| `generationConfig.responseSchema` | - |

### 参数表 6

| 状态码 | Gemini 状态 | 处理方式 |
| ----- | -------------------- | ---------------------------- |
| `400` | `INVALID_ARGUMENT` | 检查 `contents`、参数大小写和 JSON 结构 |
| `401` | `UNAUTHENTICATED` | 检查 `?key=$ROUTEMARKET_API_KEY` |
| `404` | `NOT_FOUND` | 检查模型名和路径 |
| `429` | `RESOURCE_EXHAUSTED` | 降低频率或稍后重试 |
| `500` | `INTERNAL` | 重试；如持续出现，联系支持 |

## 请求与响应示例

### 示例 1

```text
?key=$ROUTEMARKET_API_KEY
```

### 示例 2

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "Gemini API 是 Google Gemini 模型的原生内容生成接口。"
          }
        ],
        "role": "model"
      },
      "finishReason": "STOP",
      "index": 0
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 8,
    "candidatesTokenCount": 18,
    "totalTokenCount": 26
  },
  "modelVersion": "gemini-3-pro-preview",
  "responseId": "response_xxx"
}
```

### 示例 3

```json
{
  "contents": [{
    "parts": [
      {"text": "描述这张图片"},
      {
        "inlineData": {
          "mimeType": "image/jpeg",
          "data": "<BASE64_IMAGE_DATA>"
        }
      }
    ]
  }]
}
```

### 示例 4

```json
{
  "contents": [{
    "parts": [{"text": "把灯调成蓝色"}]
  }],
  "tools": [{
    "functionDeclarations": [{
      "name": "set_light_color",
      "description": "设置灯光颜色",
      "parameters": {
        "type": "object",
        "properties": {
          "color": {"type": "string"}
        },
        "required": ["color"]
      }
    }]
  }]
}
```

## 接入说明

- API 基础地址：`https://api.routemarket.ai`
- 推荐密钥环境变量：`ROUTEMARKET_API_KEY`
- 请求使用 `Authorization: Bearer <API_KEY>`。
- 上线前请用实际账号验证端点、模型名、限额与异步任务状态。
