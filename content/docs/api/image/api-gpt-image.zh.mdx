## 参数参考

### 参数表 1

| 能力 | 方法 | 路径 | 请求格式 |
| ---- | ------ | ------------------------ | --------------------- |
| 图片生成 | `POST` | `/v1/images/generations` | `application/json` |
| 图片编辑 | `POST` | `/v1/images/edits` | `multipart/form-data` |

## 请求与响应示例

### 示例 1

```text
Authorization: Bearer $ROUTEMARKET_API_KEY
```

### 示例 2

```bash
curl https://api.routemarket.ai/v1/images/generations \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一张干净的 SaaS 产品宣传图，浅色背景，真实设备展示",
    "size": "1536x1024",
    "quality": "high",
    "response_format": "url"
  }'
```

### 示例 3

```bash
curl https://api.routemarket.ai/v1/images/edits \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=保留主体，把背景改成明亮的现代办公室" \
  -F "image=@input.png" \
  -F "size=1024x1024" \
  -F "quality=high" \
  -F "response_format=url"
```

### 示例 6

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.routemarket.ai/v1",
)

result = client.images.generate(
    model="gpt-image-2",
    prompt="一张干净的 SaaS 产品宣传图，浅色背景，真实设备展示",
    size="1536x1024",
    quality="high",
    response_format="url",
)

print(result.data[0].url)
```

## 接入说明

- API 基础地址：`https://api.routemarket.ai`
- 推荐密钥环境变量：`ROUTEMARKET_API_KEY`
- 请求使用 `Authorization: Bearer <API_KEY>`。
- 上线前请用实际账号验证端点、模型名、限额与异步任务状态。
