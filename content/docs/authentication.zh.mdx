---
title: 身份验证
description: 如何对 RouteMarket API 请求进行身份验证。
---

RouteMarket 对公开网关请求使用 **API 密钥**进行验证。

## 基础地址

使用生产环境网关地址：

```text
https://api.routemarket.ai
```

如果你使用的是兼容 OpenAI 的 SDK，基础地址通常为：

```text
https://api.routemarket.ai/v1
```

## Authorization 请求头

在 `Authorization` 请求头中携带你的密钥：

```http
Authorization: Bearer <your_api_key>
```

## curl 示例

```bash
curl https://api.routemarket.ai/v1/models \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY"
```

## OpenAI SDK 示例

```ts
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.ROUTEMARKET_API_KEY,
  baseURL: "https://api.routemarket.ai/v1"
});
```

## 密钥能控制什么

RouteMarket API 密钥不仅仅是一个凭证，它还可以通过项目级和密钥级策略影响运行时行为，包括：

- 模型访问权限
- 路由可见性
- 路由偏好
- 用量限制
- 预算或速率约束

这意味着两个不同的密钥看到的模型列表或路由行为可能并不相同。

## 常见身份验证失败

常见的身份验证相关失败包括：

- `PROJECT_KEY_INVALID`
- `PROJECT_KEY_DISABLED`
- `PROJECT_LIMIT_EXCEEDED`
- `INSUFFICIENT_BALANCE`

详见 [报错与排查](/zh/guide/troubleshooting) 中的初步排查指南。
