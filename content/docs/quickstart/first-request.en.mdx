---
title: 2. Make your first request
description: Send your first request to the RouteMarket gateway with curl.
---

```bash
curl https://api.routemarket.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      { "role": "user", "content": "Say hello from RouteMarket." }
    ]
  }'
```

Once it succeeds, continue to [Use an OpenAI-compatible SDK](/en/quickstart/use-sdk).
