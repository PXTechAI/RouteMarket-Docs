本页只有一个目标：让你尽快发出一个能成功返回的请求。

## 前置条件

你需要准备：

- 一个 RouteMarket API 密钥
- 网关地址 `https://api.routemarket.ai`
- 一个逻辑模型名，例如 `deepseek-v4-flash`
- 确保账户有额度
