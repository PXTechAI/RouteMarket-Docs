This page assumes one goal: make a working request as fast as possible.

## Prerequisites

You need:

- a RouteMarket API key
- the gateway URL `https://api.routemarket.ai`
- a logical model name such as `gpt-5.4`

## Steps

1. [Set your API key](/en/quickstart/set-api-key)
2. [Make your first request](/en/quickstart/first-request)
3. [Use an OpenAI-compatible SDK](/en/quickstart/use-sdk)
4. [Add routing control when you need it](/en/quickstart/routing-control)
5. [Know what `model` means](/en/quickstart/understand-model)

## Local docs preview

```bash
corepack pnpm --filter @route-lab/docs dev
```

The docs app starts on port `3004`.
