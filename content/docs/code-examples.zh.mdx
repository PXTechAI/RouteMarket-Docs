本页收集了最简短实用的请求示例。

## curl：列出模型

```bash
curl https://api.routemarket.ai/v1/models \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY"
```

## curl：基础对话补全

```bash
curl https://api.routemarket.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      { "role": "user", "content": "Say hello from RouteMarket." }
    ]
  }'
```

## curl：带路由偏好的请求

```bash
curl https://api.routemarket.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ROUTEMARKET_API_KEY" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      { "role": "user", "content": "Summarize the platform in one sentence." }
    ],
    "routing_preference": "highest_reliability"
  }'
```

## JavaScript / TypeScript

```ts
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.ROUTEMARKET_API_KEY,
  baseURL: "https://api.routemarket.ai/v1"
});

const result = await client.chat.completions.create({
  model: "gpt-5.4",
  messages: [
    { role: "system", content: "Be concise." },
    { role: "user", content: "What is RouteMarket?" }
  ]
});

console.log(result.choices[0]?.message?.content);
```

## Python 风格 OpenAI 客户端

```python
from openai import OpenAI
import os

client = OpenAI(
    api_key=os.environ["ROUTEMARKET_API_KEY"],
    base_url="https://api.routemarket.ai/v1",
)

result = client.chat.completions.create(
    model="gpt-5.4",
    messages=[
        {"role": "user", "content": "What does RouteMarket do?"}
    ],
)

print(result.choices[0].message.content)
```

## JavaScript：指定固定服务商

```ts
const result = await client.chat.completions.create({
  model: "gpt-5.4",
  provider: "openai",
  messages: [{ role: "user", content: "Use the OpenAI path." }]
});
```

## JavaScript：使用路由偏好

```ts
const result = await client.chat.completions.create({
  model: "gpt-5.4",
  routing_preference: "lowest_price",
  messages: [{ role: "user", content: "Choose the cheapest allowed route." }]
});
```
