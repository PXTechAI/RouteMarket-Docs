RouteMarket 是一个面向团队的 AI 网关与控制平面，让你在一个地方统一管理**模型访问、路由、用量和成本可见性**。

## RouteMarket 能做什么

- 通过兼容 OpenAI 的 API 调用逻辑模型
- 在多个可能的来源之间路由请求
- 应用项目级和密钥级的访问策略
- 查看用量、定价和实际选中的路由元数据

## 核心理念

该平台建立在几个关键理念之上：

- **逻辑模型**是客户端请求时使用的名字
- **路由**是平台在运行时实际选择的目标
- **服务商、资源和资源池**描述了请求实际可以去往哪里
- **密钥策略**决定了哪些模型和路由是可用的

如果你想先了解概念层面的说明，请阅读 [核心概念](/zh/core-concepts)。
