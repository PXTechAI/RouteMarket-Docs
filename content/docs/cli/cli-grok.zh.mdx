Grok CLI 通过环境变量读取 API 接入配置，配置方式与大多数 OpenAI 兼容协议的工具类似。

## 配置文件位置

| 系统 | 路径 |
| --- | --- |
| macOS / Linux | `~/.grok/settings.json` |
| Windows | `%USERPROFILE%\.grok\settings.json` |

## 配置示例

```json title="settings.json"
{
  "env": {
    "GROK_BASE_URL": "https://api.routemarket.ai/v1",
    "GROK_API_KEY": "your-routemarket-api-token"
  }
}
```

将 `your-routemarket-api-token` 替换为你在 [创建 API 密钥](/zh/getting-started/token) 中生成的密钥。

## 测试

```bash
grok --version
grok "用一句话介绍你自己"
```

如果能正常收到模型回复，说明配置生效。
