Codex 使用 TOML 格式的配置文件，通过 `model_provider` 定义一个自定义提供方。

## 配置文件位置

| 系统 | 路径 |
| --- | --- |
| macOS / Linux | `~/.codex/config.toml` |
| Windows | `%USERPROFILE%\.codex\config.toml` |

## 配置示例

```toml title="config.toml"
model_provider = "routemarket"

[model_providers.routemarket]
name = "RouteMarket"
base_url = "https://api.routemarket.ai/v1"
env_key = "ROUTEMARKET_API_KEY"
```

同时需要设置对应的环境变量：

```bash
export ROUTEMARKET_API_KEY="your-routemarket-api-token"
```

将 `your-routemarket-api-token` 替换为你在 [创建 API 密钥](/zh/getting-started/token) 中生成的密钥。

## 测试

```bash
codex --version
codex "用一句话介绍你自己"
```

如果能正常收到模型回复，说明配置生效。连接失败时参考 [Codex 常见问题](/zh/faq2/faq-codex)。
