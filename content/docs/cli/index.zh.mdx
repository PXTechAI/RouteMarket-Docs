RouteMarket 的网关地址为 `https://api.routemarket.ai`；使用兼容 OpenAI 协议的客户端时，需要在地址末尾加上 `/v1`，即 `https://api.routemarket.ai/v1`。

大多数 CLI 工具通过环境变量或本地配置文件两种方式之一完成接入，具体取决于工具本身的设计。
