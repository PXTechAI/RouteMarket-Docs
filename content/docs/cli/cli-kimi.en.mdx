Kimi CLI reads its API configuration from environment variables.

## Config file location

| OS | Path |
| --- | --- |
| macOS / Linux | `~/.kimi/settings.json` |
| Windows | `%USERPROFILE%\.kimi\settings.json` |

## Example config

```json title="settings.json"
{
  "env": {
    "KIMI_BASE_URL": "https://api.routemarket.ai/v1",
    "KIMI_API_KEY": "your-routemarket-api-token"
  }
}
```

Replace `your-routemarket-api-token` with the token you generated in [Create an API token](/en/getting-started/token).

## Test

```bash
kimi --version
kimi "introduce yourself in one sentence"
```

A normal model reply confirms the config is working.
